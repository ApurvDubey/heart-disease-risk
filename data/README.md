# Data

The dataset is not committed (25 MB). Download `heart_2020_cleaned.csv` from
Kaggle, "Personal Key Indicators of Heart Disease" (derived from the CDC BRFSS
2020 annual survey), and place it in this folder:

    data/heart_2020_cleaned.csv

The file has 319,795 rows and 18 columns; the target is `HeartDisease` (Yes/No).
Only about 8.6% of rows are positive, which is the point of this project.
